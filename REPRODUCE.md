# REPRODUCTION GUIDE

This guide lists the exact, minimal commands required to compile and execute all verification unit tests, flash simulations, and machine learning experiments from scratch.

All benchmarks, accuracy gains, and flash wear statistics presented in the project documentation can be verified and regenerated by executing these steps on any standard x86_64 or ARM Linux/macOS terminal.

---

## 1. Prerequisites and Dependencies

The testing and simulation pipeline requires:
- **GCC Compiler**: Supporting C99 and standard sanitizers (ASan, UBSan).
- **Python 3.x**: No third-party modules or external packages are required (all scripts execute using standard Python library imports: `random`, `math`, `json`, and `struct`).

---

## 2. Command Execution Steps

### 2.1 Run C Unit Tests (ASan + UBSan Enabled)
To build and execute the transactional recovery, log-rebuilding, and wraparound consolidation unit tests, run:

```bash
gcc -Wall -Wextra -Wpedantic -fsanitize=address,undefined -Iinclude \
    tests/test_recovery.c src/virtual_weight_engine.c src/flash_driver.c \
    -o test_recovery && ./test_recovery
```

**Expected Console Output**:
```text

==================================================

[TEST] Running Reboot Recovery Test...
[PASSED] Reboot Recovery Test.
```

---

### 2.2 Run High-Fidelity Flash Simulations
To run the 1,500 training epochs simulation comparing the traditional in-place baseline write paths against FN-CLE logging, run:

```bash
python3 scripts/fn_cle_simulator.py
```

This dumps the exact metrics (erase count, bytes programmed, calculated energy, write amplification) into `results/simulation_results.json`.

---

### 2.3 Run Illustrative ML Personalization Experiments
To run the illustrative, 3-feature synthetic Gaussian classifier training loop (adapted head), run:

```bash
python3 scripts/fn_cle_ml_experiment.py
```

This trains the synthetic classifier head and saves the accuracy improvements (from 20.5% to 85.0%) into `results/ml_results.json`.
